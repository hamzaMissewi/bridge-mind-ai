## Packages
framer-motion | Page transitions and complex animations
recharts | Analytics charts for the dashboard
date-fns | Date formatting for tables and cards
clsx | Utility for conditional classes
tailwind-merge | Utility for merging tailwind classes efficiently
lucide-react | Icon set (already in base, but ensuring it's available)

## Notes
Authentication is handled via Replit Auth (/api/login, /api/logout, /api/auth/user).
The app uses a dark theme by default to match the "Bridgemind" aesthetic.
Images will use the provided assets where applicable or Unsplash for generic placeholders.
All data fetching uses TanStack Query with the provided API schema.
